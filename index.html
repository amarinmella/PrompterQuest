UNIDAD 2

El Framework RCTF

El superpoder de la estructura: Rol, Contexto, Tarea y Formato.

0%

🎯 Objetivo de Aprendizaje (OA)

Aplicar la metodología estructural RCTF (Rol, Contexto, Tarea, Formato) para diseñar instrucciones precisas y predecibles.

💡 Competencias Adquiridas

Estructuración lógica de instrucciones, adaptabilidad de roles profesionales y control de formatos de salida.

UNIDAD 3

El Framework CREA

Guía a la IA con ejemplos reales: Contexto, Rol, Ejemplo y Acción.

0%

🎯 Objetivo de Aprendizaje (OA)

Implementar técnicas de aprendizaje interactivo con ejemplos (Few-Shot Prompting) utilizando el framework CREA.

💡 Competencias Adquiridas

Diseño instruccional avanzado, aprendizaje por imitación de patrones y resolución de problemas algorítmicos.

UNIDAD 4

El Framework CREATE

Ingeniería de nivel profesional: Personaje, Tarea, Ejemplos, Ajustes, Tipo y Extras.

0%

🎯 Objetivo de Aprendizaje (OA)

Dominar el diseño de prompts complejos de nivel profesional mediante el framework CREATE (Character, Request, Examples, Adjustments, Type, Extras).

💡 Competencias Adquiridas

Programación declarativa de alto nivel, mitigación de sesgos, control estricto de restricciones y optimización de flujos de trabajo con IA.
